- [saved] Bookmark metadata holds page, selection, filter, variable, focus/display
  and per-visual snapshot state, so a bookmark is not a page link. Preserve nested
  serialization; never regenerate one from a name and destination, and never copy
  snapshot payloads between reports.
- [open] A stale bookmark may restore older data or display state after a later
  visual edit; re-capture it through the product after changing bookmarked visuals.
- When adapting a bookmark, decide whether it restores page, data and/or display,
  remap page, visual and local IDs consistently, and reconcile snapshots that store
  filter state whenever filters change.
- [saved] EDIT and READ both saved `showBookmarksPane: false` while bookmarks
  existed; a hidden pane does not delete bookmarks or prove another access route.
- [saved] A bookmark navigator's separate `navigatorButtonState.actionType: "NONE"`
  does not disable its bookmark tabs.
- [open] Tab selection, refresh after later edits, data/display restoration and
  hidden or deselected bookmark behaviour. A bookmark targeting a sheet with Marker
  Mode drawings does not prove it restores them.
- Test each bookmark tab, restored filters, visibility and trellis state, then reopen.
- [saved] Another saved bookmark stored its default flag as a `properties[]` entry
  (`property: "isDefaultBookmark"` with a string value) rather than a boolean key,
  and its `cloudMeta.bookmarkMeta` also held `activeSelection` (the selected
  visual) and `bookmarkOrder`. Keep each export's own shape and ordering; never
  convert one form into the other.
- [open] Bookmarks generated by cloning one saved snapshot as a template and
  filling it from current visual state were never runtime-tested, and their
  snapshots held no visual geometry; whether native snapshots store geometry is
  unconfirmed. A new or regenerated bookmark is not evidence that a placement
  defect was repaired.
- Treat a bookmark as saved view state, not a copy of data values or a separate
  scenario. Before promising a view switch, inspect which state the saved bookmark
  captured (filters, sort, hierarchy expansion, visibility and display), then check
  that switching views keeps formula references and slicer and context selections
  intact and neither clears nor restores unintended selections.
- Optional pattern: a summary bookmark and a detail bookmark can let one compact
  sheet tell a clear story and still reach detail without excessive scrolling.
